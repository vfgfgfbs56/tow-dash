# Проверка версии 8

Локальная проверка 26.09.2026. В аккаунт владельца код не публиковался.

| Проверка | Результат |
|---|---|
| Физика и клиентские тесты | 25 тестов: 24 прошли вместе, затем отдельно прошла проверка палитры десятого лабиринта. Среди них 50 полных трасс уровня 1 и полные трассы уровней 2–6. Проверены скорость, длительность, коллизии, подсказки и возрождение |
| 50 полных трасс уровня 1 | Оба участника финишировали без смертей. **14 161 фигура**, **643 лестницы**, **394 препятствия с кольцом**, **210 промежутков около трёх ширин куба** внутри групп |
| Уровни 2–6 | Каждый прошёл от начала до финиша с двумя участниками без смертей; число 12-секундных лабиринтов равно числу минут, по три боя с боссом |
| Переменные лестницы | В наборе трасс появились все варианты **3–6 столбов** и **1–4 активных кольца**. Для обоих игроков проверены окна прыжков, касания колец, приземления и шипы |
| Босс | **150 боёв**, по три за трассу после второй минуты. Каждый длится 16 секунд и содержит **16 снарядов** разной скорости с интервалом 0,9 секунды. В полёте одновременно максимум два снаряда; низкие требуют прыжка, высокие проходят над ним |
| Полёт и переходы | **300 полётов по 12 секунд**. В 50 трассах почти каждый полёт примыкает к перевороту через **1,5 секунды**; механики не пересекаются. Узкие/широкие коридоры проверяются для обоих участников |
| Возрождение | Над шипами игрок получает ближайшую доступную верхушку впереди и защиту до выхода с лестницы; в полёте появляется внутри коридора и следует безопасному маршруту до первого действия. Отдельные тесты проверяют отсутствие повторной немедленной гибели |
| `npm run build` | Wrangler dry-run собирает Worker и статические файлы без публикации |
| Локальный Cloudflare runtime | Два настоящих WebSocket-клиента проверяют комнату, выбор общего уровня 1, отказ для закрытого уровня 2, гостевой прогресс, управление, переподключение, паузу и полёт |
| Версия клиента/сервера | Общая физика имеет `VERSION: 8`; `/api/config` после публикации должен вернуть `version: 8` и шесть уровней |

Тест Canvas API проверяет квадратные секции лестницы без точек, метку видимого кольца до и после окна прыжка у обоих участников, шипы, босса с пулей, остаточный блок, лабиринт и подпись «ПРЫГАЙ». Повторить снимки меню версии 8 в текущем окружении не удалось: локальный бинарник Chromium повреждён и аварийно завершается при запуске. После публикации проверьте читаемость шести карточек уровня на двух реальных телефонах внутри Telegram.

Проверенная проходимость означает существование безопасной последовательности действий при заданной физике. Она не гарантирует выживание при любых нажатиях или сетевой задержке.
