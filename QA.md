# Проверка версии 3

Обновление проверено 25.09.2026. Публикация в аккаунт владельца не выполнялась.

| Проверка | Результат |
|---|---|
| `npm test` | **14 тестов прошли** |
| 50 полных шестиминутных трасс | Оба игрока прошли без гибели; **17 514 фигур**, включая **720 башен с кольцом**, все 6 типов. Проверены середина и края окон прыжка |
| Плотность по минутам, суммарно на 50 трассах | **1 348 → 2 258 → 2 728 → 3 065 → 3 728 → 4 387** фигур. Часть времени теперь отведена полёту, вокруг башен и переходов оставлено место |
| Шесть полётов на каждой трассе | Все **300 маршрутов** завершены. Один на каждую минуту, по 1 440 шагов симуляции, то есть 12 секунд. Верхняя и нижняя дорожки назначаются случайно |
| Генератор коридоров | Проверяет обе позиции и обе дорожки при 15 Гц управления, требует запас между хитбоксом и стеной не менее 12 единиц |
| Жёлтое кольцо | Автоматически усиливает прыжок при контакте в воздухе. Оба участника используют его независимо. Без кольца тестовая башня приводит к гибели |
| Ложная фигура | Бег через неё безопасен; прыжок убивает, включая пролёт выше вершины |
| Управление в полёте | Удержание поднимает, отпускание опускает. Столкновение со стеной убивает. Возрождение через 6 секунд возвращает в свой коридор |
| Таймер возрождения | Показывается только погибшему. У живого напарника центральный блок скрыт |
| Вибрация | Тестовый Telegram API получает `medium` при старте, `error` при собственной смерти, `success` при собственном возрождении. События друга и повторные снимки не дублируют сигнал |
| Звёзды | Браузерная проверка пикселей: есть над дорогой, отсутствуют под платформой. В полёте ограничены геометрией коридоров |
| Скорость и таймеры | ×2,0 → ×5,5; +0,1 каждые 10 секунд; финиш на 360-й секунде. Отсчёт старта 5 секунд, возрождение 6 секунд |
| Перевороты | Общий случайный график без пересечений с полётом, зеркальная гравитация, прыжок вниз и свободные промежутки около переходов проверены |
| Восстановление из JSON | Симуляция после сериализации совпадает, в том числе в полёте |
| Локальные цвета | Геометрия общая; каждый видит себя синим и друга красным. Проверено тестом и снимками одного полёта с двух позиций |
| Telegram HMAC | Верный, неверный и просроченный наборы данных проверены |
| `npm run build` | Worker собран Wrangler в dry-run без публикации |
| Два настоящих WebSocket-клиента в локальном Cloudflare runtime | Создание/вход, отказ третьему, нажатие/отпускание, пауза, поражение, перезапуск, переподключение, замена соединения и полные 12 секунд первого полёта без гибели прошли |
| Версия клиента/сервера | `/api/config` возвращает `version: 3`; старый протокол отклоняется |
| Chromium 1440×900 | Живой/мёртвый HUD, события вибрации, смешанное управление мышью и клавишами, отпускание при потере фокуса прошли; ошибок JavaScript нет |
| Мобильная эмуляция 844×390, touch, DPR 2 | Своя цифровая клавиатура без редактируемого поля, удержание и отмена касания в полёте прошли. Pinch ×1,7 оставляет `visualViewport.scale = 1` |
| Внешний вид | Проверены башня с кольцом, усиленный прыжок, ложная фигура, оба цвета полёта и мобильный лабиринт |

Новые снимки в `docs/`: `orb-tower.png`, `boost-jump.png`, `false-figure.png`, `flight-maze.png`, `flight-maze-friend.png`, `flight-maze-mobile.png`, `friend-respawn-hidden.png`, `own-respawn.png`.

Снимки механик сделаны рабочими `engine.js` и `render.js`: симуляция ускоренно доведена до нужного момента, затем отрисована браузером. Для управляемых UI-сценариев использовались тестовые снимки WebSocket и подменённый Telegram SDK. Отдельный сетевой тест работал с настоящими WebSocket и локальным Cloudflare runtime. Проверка пикселей звёзд проводилась на обычной дороге; ограничение в полёте проверено по отрисовке и общей геометрии.

Снимки остальных экранов сохранены из проверки версии 2: меню, клавиатура и внешний вид обычной дороги не перерабатывались. Встроенный TTF Press Start 2P с кириллицей сохранён.

На реальных устройствах iOS/Android внутри Telegram физическая вибрация и HTTPS-версия владельца здесь не проверялись. Проходимость означает существование допустимых действий при заданной физике; она не гарантирует прохождение при произвольных нажатиях или любой задержке сети. Это не нагрузочный тест.
