# Проверка версии 7

Локальная проверка 26.09.2026. В аккаунт владельца код не публиковался.

| Проверка | Результат |
|---|---|
| Физика и клиентские тесты | 22 теста, включая 50 полных шестиминутных трасс. Проверены коллизии, постоянная метка кольца, квадратные секции, возрождение на ступенях и в полёте |
| 50 полных трасс | Оба участника финишировали без смертей. **14 126 фигур**, **635 лестниц**, **449 препятствий с кольцом**, **193 промежутка около трёх ширин куба** внутри групп |
| Переменные лестницы | В наборе трасс появились все варианты **3–6 столбов** и **1–4 активных кольца**. Для обоих игроков проверены окна прыжков, касания колец, приземления и шипы |
| Босс | **150 боёв**, по три за трассу после второй минуты. Каждый длится 16 секунд и содержит **16 снарядов** разной скорости с интервалом 0,9 секунды. В полёте одновременно максимум два снаряда; низкие требуют прыжка, высокие проходят над ним |
| Полёт и переходы | **300 полётов по 12 секунд**. В 50 трассах почти каждый полёт примыкает к перевороту через **1,5 секунды**; механики не пересекаются. Узкие/широкие коридоры проверяются для обоих участников |
| Возрождение | Над шипами игрок получает ближайшую доступную верхушку впереди и защиту до выхода с лестницы; в полёте появляется внутри коридора и следует безопасному маршруту до первого действия. Отдельные тесты проверяют отсутствие повторной немедленной гибели |
| `npm run build` | Wrangler dry-run собирает Worker и статические файлы без публикации |
| Локальный Cloudflare runtime | Два настоящих WebSocket-клиента проверяют комнату, управление, переподключение, паузу и полёт |
| Версия клиента/сервера | Общая физика имеет `VERSION: 7`; `/api/config` после публикации должен вернуть `version: 7` |

Тест Canvas API проверяет квадратные секции лестницы без точек, метку видимого кольца до и после окна прыжка у обоих участников, шипы, босса с пулей, остаточный блок, лабиринт и подпись «ПРЫГАЙ». В предыдущей версии интерфейс проверялся в настоящем браузере на компьютере и мобильной эмуляции. Повторить снимки версии 7 в текущем окружении не удалось: локальный бинарник Chromium повреждён и аварийно завершается при запуске. После публикации оцените читаемость метки и лестницы на двух реальных телефонах внутри Telegram.

Проверенная проходимость означает существование безопасной последовательности действий при заданной физике. Она не гарантирует выживание при любых нажатиях или сетевой задержке.
