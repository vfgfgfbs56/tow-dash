# Проверка версии 5

Локальная проверка 26.09.2026. В аккаунт владельца код не публиковался.

| Проверка | Результат |
|---|---|
| `npm test` | 18 тестов; полные заезды и отдельные столкновения босса, лестницы, шипов, полёта и отрисовка canvas |
| 50 полных шестиминутных трасс | Оба игрока дошли до финиша без гибели; **15 367 фигур**, включая **573 шипованные лестницы**, **451 препятствие с кольцом** (208 двойных блоков) |
| Короткие связки | **196 промежутков около трёх ширин куба внутри групп**, а также **147 пар обычных групп** с интервалом менее 90% базового на 50 трассах. Генератор проверяет время приземления обоих участников до следующего действия |
| Плотность | По минутам 2 204, 2 872, 2 337, 2 122, 2 496, 3 336 фигур на 50 трассах. Третья и четвёртая минуты содержат бои и меньше дорожных препятствий; размеры обычных групп увеличиваются, базовые интервалы сокращаются |
| Боссы | **150 встреч**, по 3 за трассу после второй минуты. Каждая длится 16 секунд, выпускает ровно три снаряда различной скорости. Низкие снаряды требуют прыжка; высокий проходит над стоящим кубом. Все 150 превращений оставили блок с проверенным окном прыжка. Пересечений с полётом и переворотами нет |
| Лестница | Пять раздельных столбов, четыре промежутка с шипами и кольцо над вторым. Оба участника приземляются на четыре доступные верхушки, усиленным прыжком пролетают центральный пик и возвращаются на дорогу. Проверено на полу и потолке |
| Полёт | **300 участков по 12 секунд**: широкие камеры чередуются с узкими проходами. Обе дорожки и обе позиции проверяются при 15 Гц управления с запасом не меньше 10 единиц до стен |
| Обратная совместимость | Сохранены красная выдвижная ловушка, цвета с двух точек зрения, собственный таймер возрождения, 6 секунд до появления, вибрация Telegram и ввод кода своей клавиатурой |
| `npm run build` | Wrangler dry-run собирает Worker и статические файлы без публикации |
| Локальный Cloudflare runtime | Два настоящих WebSocket-клиента проверяют вход, управление, переподключение, паузу и полёт |
| Клиент и Worker | Общая физика имеет `VERSION: 5`; `/api/config` должен вернуть `version: 5` после деплоя |

Код отрисовки v5 прогнан через Canvas API в тесте `tests/render.test.js` для столбов, шипов, босса с пулей, оставшегося блока и полёта. Предыдущая версия прошла настоящую браузерную проверку на компьютере и мобильной эмуляции. Повторить снимки v5 в текущем окружении не удалось: имеющийся локальный бинарник Chromium повреждён и аварийно завершается при запуске. Это ограничение визуальной проверки, не ошибка Worker. Перед использованием на двух телефонах стоит оценить читаемость босса и узких коридоров внутри Telegram.

Проходимость означает существование проверенной последовательности действий при заданной физике, а не гарантию выживания при любых нажатиях или сетевой задержке. Архив содержит `README.md` и `UPDATE.md` с инструкцией публикации.
